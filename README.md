# 500 навыков для Claude Code

Интерактивный лендинг с каталогом из 500 профессиональных навыков для Claude Code, разбитых на 12 тематических паков: контент, продажи, видео, дизайн, операционка, маркетинг, исследования, документы, агенты и разработка.

## Возможности лендинга
- **Интерактивный симулятор Claude**: демонстрация установки сетапа одной строкой и выполнения задач в реальном времени.
- **Интерактивный выбор сценариев**: примеры генерации рилсов для Instagram, холодных писем, скриптов YouTube Shorts, постов LinkedIn и настройки магазина Shopify.
- **Стена навыков (The Wall)**: каталог всех 500 навыков с фильтрацией по пакам (71 навык контента, 58 разработки, 48 видео, 45 дизайна и т.д.).
- **Таймер обратного отсчёта и динамический расчёт цены** (интеграция с `offer.json`).
- **Шрифтовая пара**: плотный гротеск `Inter Tight` + ретро-пиксельные `Pixeboy` и `Tiny5` с полной поддержкой кириллицы.
- **Полная адаптивность**: поддержка настольных и мобильных устройств.

## Локальный запуск
Просто откройте `index.html` в браузере или запустите локальный статический сервер:
```bash
python3 -m http.server 8000
```
И перейдите по адресу: [http://localhost:8000](http://localhost:8000)
